# 🍺 건배 — 30초 타임어택

퇴근길, 한 손으로 즐기는 **맥주 따르기 타임어택 게임**.
30초 안에 완벽한 맥주를 최대한 많이 따라 랭킹에 도전하세요.
화면을 꾹 눌러 따르고, **폰을 기울이면 거품이 덜 생겨요** — 진짜 맥주처럼!
완벽하게 따르면 친구가 짠— 하고 건배해 줍니다.

설치도, 앱스토어도 필요 없어요. 아이폰 사파리로 열어서 바로 즐기면 됩니다.

## 📱 아이폰에서 바로 즐기기

### 방법 1. GitHub Pages 주소로 열기 (권장)
이 저장소에는 자동 배포 워크플로(`.github/workflows/pages.yml`)가 들어 있어요.

1. GitHub 저장소 → **Settings → Pages**
2. **Build and deployment → Source** 를 **GitHub Actions** 로 설정
3. 잠시 뒤 발급되는 주소(예: `https://<사용자>.github.io/acom/`)를
   아이폰 **사파리**에서 열기
4. 공유 버튼 → **홈 화면에 추가** → 앱처럼 전체화면 + 오프라인 실행 ✨

### 방법 2. 파일 하나로 바로 실행
인터넷 없이도 됩니다. `index.html`을 아이폰으로 옮겨(또는 메일/메신저로 보내)
사파리로 열면 바로 플레이할 수 있어요. (아이콘 설치까지 원하면 방법 1을 추천)

## 🎮 플레이 방법 — 30초 타임어택
- **꾹 누르기** → 맥주를 따릅니다. **손 떼기** → 멈춰요.
- 거품까지 포함한 높이를 **노란 점선(목표선)** 에 딱 맞추면 고득점!
- 📱 **폰을 기울이면 거품이 덜 생겨요** — 실제로 잔을 비스듬히 대고 따르는 것처럼.
  거품을 줄여 정확히 채우고, 끝에 살짝 세워 적당한 거품 머리를 만들면 **완벽!**
  (기울기 센서가 없는 기기/PC에서는 따르는 중 **좌우로 드래그**하면 됩니다.)
- **완벽한 한 잔**은 친구와 건배 🍻 + **시간 +1.5초** 보너스.
- 넘치면 0점. 30초가 끝나면 점수 합계로 **랭킹**에 도전!

랭킹(상위 10명 이름·점수)은 기기에 저장됩니다.
> 온라인 글로벌 랭킹은 별도 서버가 필요해요. 원하면 백엔드 연동을 추가할 수 있습니다.

## 🛠 구성
| 파일 | 설명 |
|------|------|
| `index.html` | 게임 전체 (Canvas + WebAudio, 외부 라이브러리 없음) |
| `manifest.webmanifest` | PWA 매니페스트 (홈 화면 설치, 세로 고정) |
| `service-worker.js` | 오프라인 캐싱 |
| `icons/` | 앱 아이콘 (180/192/512) |
| `tools/make_icons.py` | 아이콘 생성 스크립트 (Python 표준 라이브러리만 사용) |
| `.github/workflows/pages.yml` | GitHub Pages 자동 배포 |

아이콘을 다시 만들려면:
```bash
python3 tools/make_icons.py
```

순수 HTML/CSS/JS라 빌드 과정이 없습니다. 로컬에서 보려면 아무 정적 서버나 쓰면 돼요:
```bash
python3 -m http.server 8000   # http://localhost:8000
```

오늘도 수고 많았어요. 짠! 🍻
